# Publicación del sitio

Este sitio se publica con GitHub Pages desde este repositorio. Para desplegarlo nuevamente en la misma dirección (`https://proyectoddef.github.io/emilianonaranjo/en/index.html`), sigue estos pasos:

1. Asegúrate de que la rama `main` tenga la carpeta `en/` con el archivo `index.html` (ya incluida en este repositorio).
2. Sube también la carpeta `Images/` si necesitas recursos multimedia.
3. En GitHub, ve a **Settings > Pages** y selecciona que GitHub Pages use la rama `main` y la carpeta `/ (root)` como fuente. GitHub generará automáticamente el sitio.
4. Si ya tenías una versión previa publicada, puedes forzar la actualización haciendo un commit con todos los archivos y empujándolo a `main`. GitHub Pages reconstruirá el sitio y quedará accesible en la misma URL.
5. En caso de que el navegador muestre la versión antigua, limpia la caché o abre una ventana privada para ver los cambios.

La ruta `/en/index.html` está disponible porque el archivo se encuentra en `en/index.html` dentro del repositorio. Si deseas ofrecer el sitio también en la raíz (`https://proyectoddef.github.io/emilianonaranjo/`), mantén o actualiza el `index.html` principal en la raíz.
